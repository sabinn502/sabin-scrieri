SAE — site literar minimalist

Fișiere:
- index.html: designul și funcțiile site-ului
- writings.json: scrierile afișate pe site
- .pages.yml: configurarea editorului Pages CMS

PUBLICARE / ACTUALIZARE PE GITHUB
1. În repository-ul GitHub sabin-scrieri, apasă Add file > Upload files.
2. Încarcă index.html, writings.json și .pages.yml din acest folder.
3. Dacă GitHub întreabă dacă dorești să înlocuiești index.html, confirmă și apasă Commit changes.
4. Păstrează repository-ul pe Public și GitHub Pages setat la main / (root).

EDITOR PENTRU SCRIERI
1. Intră pe https://app.pagescms.org/ și autentifică-te cu GitHub.
2. Instalează/autorizează aplicația Pages CMS pentru repository-ul sabin-scrieri.
3. Deschide repository-ul sabin-scrieri, ramura main.
4. Pages CMS va citi .pages.yml și va afișa colecția „Scrieri”.
5. Poți adăuga, edita sau șterge texte. Salvează/commit schimbările; GitHub Pages va actualiza site-ul după câteva minute.

Site-ul nu folosește imagini în design. Textele sunt exemple și pot fi editate sau șterse.
